# DESIGN_SYSTEM.md — 見た目の規則（Calibrated Instrument）

画面の配色・書体・余白・部品の規則です。実装の Source of Truth は
`src/index.css` の semantic token で、各コンポーネントはそれだけを参照します。
画面ごとの構成（何をどの順に置くか）は `docs/UI_SPEC.md` を参照してください。

## 1. コンセプト

**Calibrated Instrument** — 3 投を測る精密な計器。

- 本体は無彩色。Dark はグラファイト、Light はアルミ。
- 主操作は「反転」で示す。Dark ではチョーク色の面にインクの文字、Light ではその逆。
  装飾のための色（グラデーション・発光・ブランド色）は持たない。
- **色は意味にだけ使う。** 推奨度 S / A / B / C、判定（良い・見直し・誤り）、
  盤面の実物の配色、盤面で指している的（target）。
- **数字が主役。** 残り点・ターゲット・本数は、幅を詰めた等幅数字で大きく組む。
  入力欄や残り点の表示は「凹んだ窓」（`--surface-alt` + `--inset-well`）に置く。

## 2. 色

| token | Dark | Light | 用途 |
| --- | --- | --- | --- |
| `--background` | `#15181b` | `#e7e9ec` | 画面の地。`theme-color` と manifest も同じ値 |
| `--surface` | `#1c2024` | `#f6f7f8` | パネル |
| `--surface-alt` | `#111417` | `#e0e3e6` | 凹んだ窓（入力・数字の表示・セレクターの溝） |
| `--surface-elevated` | `#23282d` | `#ffffff` | 浮かせる面（答えのカード・得点入力） |
| `--text` | `#eeece7` | `#15181b` | 本文・数字 |
| `--text-secondary` | `#b5b9be` | `#444b53` | 補足 |
| `--text-dim` | `#8e949b` | `#5b626b` | 注記（本文サイズでも 4.5:1 以上） |
| `--accent` | `#eeece7` | `#15181b` | 主操作・選択中の面（反転） |
| `--grade-s/a/b/c-*` | 緑 / 青 / 黄 / 赤 | 同系の濃色 | 推奨度。判定の 良い / 見直し / 誤り にも同じ系統を使う |
| `--target` | `#e3a64a` | `#845000` | ルートのチップで盤面の位置を確かめている的（盤面の focus と同じ色） |
| `--segment-*` / `--board-*` | 実物のダーツボード | 同左 | 盤面。テーマで大きく変えない |

- 推奨度・判定の色は**文字（S / A / B / C、判定名）と必ず併記**する。色だけで区別しない。
- 理由の極性（強み / 注意）も色に加えて `+` / `−` の記号を置く。
- コントラストは本文 4.5:1、大きな文字 3:1 以上（WCAG 2.x AA）を両テーマで満たす。

## 3. 書体

- **Archivo**（可変幅 62–125%・可変ウェイト、SIL OFL 1.1）。ラテン文字のサブセットだけを
  `src/assets/fonts/` に同梱し、Service Worker で precache する（オフラインでも同じ表示）。
  ライセンスは `src/assets/fonts/OFL-Archivo.txt`。
- 日本語は端末のシステムフォント（Hiragino Sans / Noto Sans JP / Yu Gothic UI / Meiryo）。
  日本語の Web フォントは容量が大きく、オフライン PWA の precache を膨らませるため同梱しない。
- 数字は `font-stretch: 74–78%` + `font-variant-numeric: tabular-nums`。
  残り点・ターゲット・統計・表など、桁がそろって欲しい所にだけ使う。
- 見出し・区画名は日本語の文として置く。英大文字の飾りラベル（`APPEARANCE` など）は置かない。
  `CHECKOUT` / `SETUP` / `STANDARD` / `BEST` / `MY ROUTE` / `NEXT VISIT` / `LEFT` / `DARTS` /
  `BUST` などは、競技とこのアプリの用語なのでそのまま使う。

| token | 値 | 主な用途 |
| --- | --- | --- |
| `--text-2xs` | 0.6875rem | 札（バッジ）・単位 |
| `--text-xs` / `--text-sm` | 0.75 / 0.8125rem | 注記・補足 |
| `--text-md` / `--text-base` | 0.9375 / 1rem | 本文 |
| `--text-lg` / `--text-xl` | 1.1875 / 1.5rem | 小さなターゲット表示・小見出し |
| `--text-2xl` / `--text-3xl` | 2 / 2.75rem | 計器の読み取り値 |

## 4. 余白・形

- 余白は 4px 基準（`--space-1` 0.25rem 〜 `--space-8` 3rem）。
- 角丸は階層で変える。札 3px（`--radius-xs`）/ ボタン・入力 6px（`--radius-s`）/
  パネル 10px（`--radius-m`）。ピル型のボタンは使わない。
- タップ領域は 44×44 CSS px 以上（`--tap`）。
- 内容の最大幅は 76rem。文章は 44rem 前後に収める。

## 5. 部品

| 部品 | 規則 |
| --- | --- |
| セレクタースイッチ | ナビ・残り本数・TRAINING のモード・SIMULATION の選択肢。凹んだ溝の中で、選んだものだけが反転して浮く |
| 主ボタン | `--accent` の面 + `--accent-contrast` の文字。1 画面に 1 つを原則にする |
| 副ボタン | 透明 + `--border-strong` の枠 |
| 表示窓 | `--surface-alt` + `--inset-well`。残り点の入力・StatusBar・3 投の並び・回答枠 |
| 答えのカード | `--surface-elevated` + `--shadow-md`。札（STANDARD / BEST）を反転させる |
| 候補の一覧 | カードを積まず、1 枚のパネルを罫線で区切る。推奨度の札は行の右端でそろえる |
| 開閉 | 文言（理由を見る / 閉じる）+ 回転する山形。`aria-expanded` と連動 |
| 注意 | 左の色帯 + 淡い地。危険（Bust・ノーテン）は赤系、判定は推奨度と同じ系統 |

## 6. 動き

- 操作に応えるものだけ。答えのカード・採点結果・得点入力・BUST / CHECKOUT の表示が
  現れるときに一度だけ `reveal`（不透明度・260ms）。開閉は同じ `reveal` を 180ms で。
- 位置は動かさない（transform のアニメーションは使わない）。答えが現れる位置が一瞬でも
  ずれると、読みはじめの視線と、位置を前提にしたスクロール処理の両方を乱すため。
- 押したときは `scale(0.985)`。ホバーで要素を浮かせたり動かしたりしない。
- 画面全体のフェードや、繰り返し再生される演出は入れない。
- `prefers-reduced-motion: reduce` ではすべて止める（`src/index.css`）。
  動きが無くても、状態は文字と色で伝わる。

## 7. レイアウト

| 幅 | 構成 |
| --- | --- |
| 〜47.9rem | 1 列。ヘッダーは「アプリ名・設定」+ 2 段目にモードの切り替え |
| 48rem〜 | 入力・設定パネルを横長にまとめる。ホームは 2×2 |
| 64rem〜 | ヘッダーを 1 行に。CHECKOUT / SETUP は「答え・実戦入力」｜「他の候補」の 2 列、TRAINING / SIMULATION は「盤面」｜「状況・入力・結果」の 2 列。ホームは 4 列 |

2 列にするときも DOM の順序は変えない（読み上げ順とスクロールの挙動はスマートフォンと同じ）。
